## Fixes

- Translating a page preserves edits the website makes while translation is running. Find updates its matches when text changes or becomes visible.
- Website icons retry after failed loads. Clearing a profile’s icons waits for pending writes from its windows.
- Downloads report interrupted transfers correctly, and a page saved to disk stays listed after its tab closes.
- Windows opened by extensions include all requested URLs in order.
- Pre-import backups keep the new copy and the four most recent earlier copies. If an older backup is locked, the import finishes with a notice. Exports and imports check the same size and profile limits.
- Early preserves saved passwords when it temporarily loses access to the vault on disk.
