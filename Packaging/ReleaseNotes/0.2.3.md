## Fixes

- Clearing history applies across windows in the same profile, and quitting waits for browsing history to save.
- Rapid page title changes do less work while keeping the final title and every visit.
- Password CSV exports run in the background with progress and cancellation.
- Saved HTTP logins can be selected on matching HTTPS sites.
- A failed password vault reset preserves the original vault, and locking Passwords invalidates pending unlock requests.
- Extension and download decisions honor current permissions, and settings save in the background.
